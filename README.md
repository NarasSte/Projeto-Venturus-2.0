<p align="justify">
  Nosso projeto tem como objetivo principal facilitar o acesso das pessoas aos cuidados com a saúde, com a nossa plataforma digital, para que as pessoas que necessitam de atendimentos rápidos ou urgentes não tenham que se deslocar para cuidarem de sua saúde, com nossa plataforma, os número de pessoas que passam mal em fila de postos de saúde e hospitais irá diminuir.
</p>


<p align="justify">
 Os usuários podem utilizar nosso site com facilidade basta fazer um cadastro e logar no site para que tenha acesso à informações de consultas como: data; hora; médico que irá atender; entre outras. Para maior flexibilidade o site oferece consultas presenciais e online quando possível.
Os doutores(as) poderão ter acesso às suas consultas virtualmente, sem que haja a necessidade de alguém para avisá-lo a todo momento, com a flexibilidade de horário, o médico poderá também se organizar melhor e escolher o melhor horário para atendimento online, caso haja algum imprevisto, com a opção de consultas online, ele não será tão prejudicado.
Com isso melhoraremos a experiência do paciente e do doutor.
</p>

<h3 align="center">📌 Descrição da Estrutura do Repositório</h3>

<p align="justify">
Usamos o <strong>back end</strong> para fazer grande parte da interface do site, utilizando dele para registro, login e salvar o login de clientes.
Também é utilizado para permitir que o usuário envie sua foto de perfil, além de controlar o <strong>modo escuro</strong> do site.
</p>

<p align="justify">
Foi utilizada uma base de dados para salvar as informações do cliente, como email e senha, bem como o link da foto associada à conta.
No <strong>front end</strong> está toda a estrutura visual do site, como páginas de Home e Sobre Nós.
</p>

<h4>🛠️ Para Funcionamento do Projeto:</h4>
<ul>
  <li>É necessário ter instalado: <strong>JavaScript, Python, HTML e CSS</strong></li>
  <li>Bibliotecas Python utilizadas:
    <ul>
      <li>Flask</li>
      <li>Flask_cors</li>
      <li>Werkzeug</li>
    </ul>
  </li>
  <li>Ao rodar o projeto localmente, o servidor Python deve ser iniciado pelo CMD, mantendo o back end ativo em segundo plano para conectar com o banco de dados e com o restante da aplicação.</li>
</ul>
